# 実装後レビュー依頼プロンプト

Codexで一度実装した後、別セッションまたは追加依頼で以下を投げるとレビューしやすいです。

```text
実装済みの Tango系 Python プロトタイプをレビューしてください。

観点:
1. ルール判定に抜け漏れがないか
2. ソルバーが一意解チェックとして正しく動くか
3. count_solutions(limit=2) が適切に打ち切られているか
4. 問題生成が偶然 solution に依存しすぎていないか
5. JSON形式がAndroid移植に適しているか
6. テストケースが不足していないか
7. 6x6で100問生成したときに安定するか

必要であれば修正してください。
Android/Kotlinへの移植はまだ行わないでください。
```
